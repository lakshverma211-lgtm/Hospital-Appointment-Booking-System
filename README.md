# Hospital Appointment System

A simple Java console-based Hospital Appointment Management System made using basic Object-Oriented Programming concepts.  
This project was created as a first-year B.Tech mini project using Java.

---

## Features

- Book doctor appointments
- Cancel appointments
- Check slot availability
- Display all appointments
- Simple menu-driven console interface
- Uses Java OOP concepts and arrays

---

## Technologies Used

- Java
- OOP Concepts
- Arrays
- Scanner Class

---

## Project Structure

- `Doctor` class → Stores doctor details
- `Patient` class → Stores patient details
- `Appointment` class → Stores appointment information
- `AppointmentManager` class → Handles booking, cancellation, and display
- `Main` class → Runs the application
